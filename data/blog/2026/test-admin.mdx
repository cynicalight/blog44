## 阶段二：工业级大模型系统构建 (斯坦福 CS336)

直接对标真实的大模型开发流水线。对于后续涉及分布式或算力调度的构想，建议使用 WezTerm 连接你的 Ubuntu 云服务器（腾讯云）进行模拟操作与基建调研。

### Day 3：架构剖析与显存核算 (Lec 1-4)

- [ ] **理论学习**：梳理混合专家模型（MoE）的架构演进历史。
- [ ] **理论学习**：吃透模型训练的资源核算（Resource Accounting）。
- [ ] **能力自测**：给定 Llama-7B 模型，分别计算其在推理和训练状态下的精确显存消耗（涵盖权重、优化器状态、激活值）。推演 16GB 本地内存与云端 GPU 的加载差距。

### Day 4：GPU硬件编程与算子极致优化 (Lec 5-6)

- [ ] **理论学习**：对比 GPU 显存层级中 SRAM 与 HBM 的带宽差异。
- [ ] **源码阅读**：发挥 C++ 算法与内存管理基础，啃下简化版 FlashAttention 的 Triton Kernel 伪代码。
- [ ] **能力自测**：解释当下算力为何受困于“**内存墙**”，并推演 FlashAttention 是如何通过分块（Tiling）实现 $O(N^2)$ 级别性能优化的。

### Day 5：分布式训练集群调度 (Lec 7-8)

- [ ] **理论学习**：攻克大模型训练的“三维并行”：数据并行（DDP）、张量并行（TP）和流水线并行（PP）。
- [ ] **实战演练**：在 Ubuntu 服务器上模拟配置多机多卡的分布式训练拓扑与环境变量。
- [ ] **能力自测**：手画 All-Reduce、All-Gather 的底层通信逻辑图，并计算它们在不同并行切分策略下的网络带宽开销。

### Day 6：Scaling Laws与推理基建 (Lec 9-11)

- [ ] **理论学习**：深入理解预训练的 Scaling Laws（扩展定律）。
- [ ] **理论学习**：研究推理期显存管理与 vLLM 框架设计。
- [ ] **能力自测**：在给定算力（FLOPs）预算的限制下，推导出最佳的模型参数规模与训练数据量比例。
- [ ] **能力自测**：系统阐述 PagedAttention 的核心分页机制，对比贪婪搜索与束搜索（Beam Search）的内存代价。

### Day 7：工业级数据工程 (Lec 13-14)
- [ ] **理论学习**：拆解从 Common Crawl 原始网页中提取、过滤高质量预训练语料的全流程。
- [ ] **算法深挖**：研究 MinHash 等海量数据去重算法的数学原理。
- [ ] **能力自测**：设计一条应对 TB 级别文本的高并发数据处理流水线，说明如何避免“Garbage in, garbage out”。

### Day 8：大语言模型对齐前沿 (Lec 15-17)

- [ ] **理论学习**：系统复盘 SFT、RLHF 以及 DPO 技术。
- [ ] **深度对比**：将传统的 PPO/RLHF 与前沿的组相对策略优化（GRPO）、学习排序（LTR）对齐方案放在同一宏观框架内审视。
- [ ] **能力自测**：剖析上述几类对齐算法在梯度估计方差、收敛稳定性以及训练显存占用等维度的核心差异。

### Day 9：白板推演与全局串联 (模拟面试)

- [ ] **全景串联**：全程闭卷，在白板上画出“**数据清洗去重 -> 配置分布式通信 -> 算子级优化 -> Transformer预训练 -> 强化学习对齐**”的完整工业级流水线。
