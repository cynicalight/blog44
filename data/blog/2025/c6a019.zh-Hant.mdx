### 安裝插件

VSCode 搜 Java，直接無腦把第一頁的 Java 插件全裝上，省事。

![](https://bu44er-1313346488.cos.ap-shanghai.myqcloud.com/bu44er-ink/assets/78/78b2e16081deade507ef3da195a5e30af011ba8124b352f7470cd810f75f4972.png)

### 配置 launch.json

來到運行和調試界面：

![](https://bu44er-1313346488.cos.ap-shanghai.myqcloud.com/bu44er-ink/assets/67/673e1de755e1b73080d55619396cdfe024a4770283b85a698e520ee07203a2d3.png)

建議創建 `launch.json` 文件，並配置。

默認配置如下：

![](https://bu44er-1313346488.cos.ap-shanghai.myqcloud.com/bu44er-ink/assets/46/46ba16d59c4ed3bcc581498dd4e9c944847ce27702c8163fbaedf4e66cb63564.png)

其中 config 中每個對象分別對應左側`运行和调试`欄頂部的一個選項：

![](https://bu44er-1313346488.cos.ap-shanghai.myqcloud.com/bu44er-ink/assets/d0/d021feecceb22d7cdc4feb8938163f3b338a1f6bf72b6ee4acc73eaacdaa7f47.png)

接下來我們添加一個config項 `Launch with Arguments Prompt`：

- 這個選項可以在調試的時候輸入參數，非常必要

![](https://bu44er-1313346488.cos.ap-shanghai.myqcloud.com/bu44er-ink/assets/58/58a2766af1c96bdf51083eac6bc036f6c96195c7f2c9109bdf4fcd59be1d0def.png)

直接在空白處輸入 java 就會彈出選項，VSCode 會自動補全你想要的配置：

![](https://bu44er-1313346488.cos.ap-shanghai.myqcloud.com/bu44er-ink/assets/e8/e8e9f57a978bc02e52957f4ba9285b69aacf8551653ad0294e0047fa9cb23727.png)

之後就可以正常下斷點，愉快的開始調試了。
