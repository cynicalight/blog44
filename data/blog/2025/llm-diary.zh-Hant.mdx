## Concept

### 復讀機現象

- 模型傾向於無限地複製輸入的文本或者以過度頻繁的方式重複相同的句子或短語。

原因：

- data bias：大量的重複文本，質量低
- 任務太單一

### logits

logits 是模型的“原始輸出”（在softmax層之前），表示每個 token 的打分，沒經過任何概率歸一化處理。

- 一般表示為向量 $z = (z_1, z_2, …, z_n)$

在訓練中，logits 會傳入 softmax 轉為概率，再計算 loss：

$$
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

#### logprobs

logprobs 是 token 被預測為某個值的對數概率，即：

$$
\text{logprobs}(z_i) = \log \left( \frac{e^{z_i}}{\sum_j e^{z_j}} \right) = z_i - \log\left( \sum_j e^{z_j} \right)
$$

- logprobs 是 logits 經過 softmax 後的 log 值（log softmax）；

通常用於：

- 預測 top-k 的 token（概率最大的 token）
- 計算 perplexity
- 分析 token 被預測的置信度

由logits計算logprobs：

```python
import numpy as np

# 假设从模型中得到的logits
logits = np.array([2.0, 1.0, 0.1])

# 计算Softmax概率
exp_logits = np.exp(logits)
probabilities = exp_logits / np.sum(exp_logits)

# 计算logprobs
logprobs = np.log(probabilities)

# 输出结果
print("Logits: ", logits)
print("Probabilities: ", probabilities)
print("Log-probabilities: ", logprobs)
```

## Coding

### world_size

報錯信息：

```bash
Config mesh_device None world_size = 8
```

world_size 等於 num_processes，約等於分佈式訓練中GPU的個數。

可以在訓練命令中通過修改 num_processes 參數來修改 world_size:

```bash
accelerate launch --num_processes=2
```
